This folder pilots sprint simulations using OpenSim AD.

It is run in the environment set-up prescribed by the TGCS 2023 OpenSim Workshop (see: https://simtk-confluence.stanford.edu:8443/display/OpenSim/ISB+Technical+Group+on+Computer+Simulation+%28TGCS%29+2023+OpenSim+Workshop) and with the code included with the `opencap-processing` instructions.

Comments throughout code in this piloting folder provided further info.
